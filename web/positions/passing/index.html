Position

Passing their open guard (top)

Control legs or hips before you move. Pass to side control and pin before they recover a frame.

Moves from here

Pass

  • Knee cut (knee slice) pass → Side control
  • Body lock pass → Side control
  • Toreando (bullfighter) pass → Side control
  • Leg drag pass → Side control
  • Over-under pass → Side control
  • Headquarters position: knee slice and backstep options → Side control
  • Double-under (stack) pass → Side control
  • Leg weave pass to mount → Mount
  • Inside position passing: hands and knees first → Side control
